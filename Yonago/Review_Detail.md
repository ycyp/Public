# 三、票券攻略

## 1. 必買：Discover Another Japan Pass SAN'IN 1 Day

### 基本資料

- 成人：**3,000 日圓**
- 兒童：1,500 日圓
- 有效期：啟用後連續 24 小時
- 使用區域：鳥取縣、島根縣指定景點
- 使用方式：在專用 App 登錄票券，於指定景點掃描 QR Code
- 購買對象：訪日外國旅客
- **只包含指定景點門票，不包含 JR、巴士、租車及計程車**

### 你的回本試算

| D2 景點 | 成人原價 | Pass 是否可用 |
|---|---:|---|
| 足立美術館 | 2,500 日圓 | 是 |
| 松江城 | 1,200 日圓 | 是 |
| 堀川遊覽船 | 約 2,000 日圓 | 是 |
| 三項合計 | 約 5,700 日圓 |  |

只要完成足立美術館＋松江城：

- 單買：3,700 日圓
- Pass：3,000 日圓
- **至少省 700 日圓**

若再搭堀川遊覽船：

- 單買：約 5,700 日圓
- Pass：3,000 日圓
- **約省 2,700 日圓**

### 啟用方式

1. 出發前下載 Discover Another Japan Pass App。
2. 建立帳號並登錄購買序號。
3. 不要在台灣、飯店或前往安來途中提前啟用。
4. **10/31 抵達足立美術館入口，確認準備入場時才啟用。**
5. 在足立美術館、松江城及堀川遊覽船入口依 App 指示掃描 QR Code。
6. 手機必須保持可上網，建議準備 eSIM、SIM 卡或漫遊。

### 重要原則

- 買 Pass 不代表一定要搭堀川遊覽船。
- 足立美術館＋松江城已經回本。
- 若候船太久、天候不佳或已接近末班，直接刪除遊船。
- 不要為了「多用一次 Pass」破壞整體行程。

---

## 2. 不建議：SAN'IN 3 Day Pass

### 價格

- 3 Day：6,000 日圓

### 為什麼不買

你的可用景點主要是：

- D2 足立美術館
- D2 松江城
- D2 堀川遊覽船
- D4 水木茂紀念館

若 D2 有搭遊船，門票合計約 6,700 日圓，3 Day Pass 只省約 700 日圓；但若因時間或天氣刪掉遊船，合計只剩約 4,700 日圓，買 3 Day 反而虧錢。

**結論：1 Day 幾乎確定回本，3 Day 會限制行程彈性。**

# 四、D1｜10/30（五）：抵達米子

## 正式行程

| 時間 | 行程 | 注意事項 |
|---|---|---|
| 16:50 | 抵達米子鬼太郎機場 | 入境、領行李抓 40～60 分鐘 |
| 17:35～18:15 | 前往米子站 | 優先使用配合國際航班的接駁巴士，備案為 JR 境線 |
| 18:20～19:00 | 抵達米子、飯店入住 | 推薦住米子站步行 5 分鐘內 |
| 19:30～21:00 | 晚餐 | 星期五的燒肉或海鮮店建議預約 |

## 交通選擇

### 第一選擇：機場接駁巴士

- 米子鬼太郎機場至米子站約 25 分鐘。
- 現行成人票價約 640 日圓。
- 出關後直接確認對應台灣航班的巴士站牌與發車時間。

### 第二選擇：JR 境線

- 從航廈步行至米子空港站。
- 米子空港站至米子站約 30～35 分鐘。
- 班距較長，不要把「下飛機後理論上能接到的第一班」當成必要目標。

## 為什麼不正式安排境港

- 水木茂紀念館已關閉。
- 多數商店與咖啡店傍晚結束營業。
- 晚間海鮮餐廳選擇較白天少。
- 還需再搭 40～50 分鐘 JR 返回米子。

若班機準時、精神很好且已確認餐廳營業，可把境港夜景當臨時支線，但不要預先綁死。

## 晚餐推薦

### 正式晚餐：燒肉一八 朝日町本店

- 主題：鳥取和牛燒肉
- 適合：第一晚吃一頓正式晚餐
- 交通：從米子站搭計程車較方便
- 預算：每人約 4,000～7,000 日圓
- 星期五建議預約

### 輕鬆晚餐：肉ごっつお 米子駅前店

- 主題：牛骨拉麵
- 優點：米子站前、晚到最方便
- 推薦：ごっつおらーめん

### 牛骨拉麵專門店：たかうな 米子西福原店

- 優點：專門店型牛骨拉麵
- 缺點：不在米子站旁，需搭計程車
- 較適合 D3 還車前後，而非抵達當晚硬跑

## 住宿

- 米子站前

- 松江城天守是第二優先。
- 塩見繩手第三。
- 堀川遊覽船為時間允許才加入。

## 足立美術館接駁策略

### 目標班次

- 安來站 08:50 → 足立美術館 09:10
- 足立美術館 12:00 → 安來站 12:20

### 備案

- 08:50 免費接駁滿員時，改下一班免費接駁。
- 或視當期時刻使用安來市 Yellow Bus。
- 若去程延誤，先縮短松江周邊散步，不縮足立美術館到 90 分鐘。

## 午餐推薦

### 第一選擇：出雲そば処 八雲庵

- 地點：松江城北側、塩見繩手附近
- 推薦：割子蕎麥、鴨南蠻
- 優點：環境與城下町主題一致
- 風險：營業時間短、蕎麥可能售完
- 原則：13:00 前後抵達，排隊太長就換店

### 第二選擇：手打 神代そば

- 適合：重視蕎麥本身
- 同樣位於松江城北側
- 出發前再次核對公休日與當日營業

### 緊急備案：松江站周邊蕎麥

若足立回程延誤，直接在松江站周邊快速用餐，不為名店犧牲松江城。

## 堀川遊覽船判斷

### 搭乘條件

- 15:30 前完成松江城
- 16:00 最終運航前趕得上
- 候船不超過 15～20 分鐘
- 沒有中大雨或強風

### 直接刪除條件

- 足立接駁延誤
- 午餐排隊過久
- 松江城參觀超時
- 候船過長
- 天候不佳

**票券包含不等於一定要搭，時間比回本更重要。**

## 晚餐

- D1 若吃燒肉，D2 吃米子海鮮居酒屋。
- D1 若吃牛骨拉麵，D2 可安排燒肉一八。
- 星期六晚餐建議預約。

## 住宿

- 米子站前

# 六、D3｜11/1（日）：大山紅葉自駕專日

## 當日核心原則

- 11/1 是星期日，而且處於大山紅葉候選期。
- 鍵掛峠停車容量有限，必須清晨優先。
- 不追求完整繞完環狀道路。
- 下午提早下山，不在山區等到日落。

## 租車準備

- 提前預約米子站前租車。
- 確認最早取車時間，理想為 07:00～07:30。
- 若店家只能 08:00 取車，取車後仍直接前往鍵掛峠。
- 選小型車即可，小車較適合山路會車與停車。
- 攜帶：台灣駕照、日文譯本、護照、信用卡。
- 建議加購完整免責補償。

## 詳細時間表

| 時間 | 行程 | 注意事項 |
|---|---|---|
| 07:00～07:30 | 米子站取車 | 驗車、確認油種、導航與 ETC |
| 07:30 | 米子出發 | 導航先設鍵掛峠展望台 |
| 08:25～08:50 | 抵達鍵掛峠 | 紅葉週日預留壅塞時間 |
| 08:30～09:30 | 鍵掛峠 | 觀景、拍照；濃霧時不久候 |
| 09:30～10:30 | 環狀道路精華段 | 依道路管制與車流調整 |
| 10:30～11:00 | 桝水高原 | 前段塞車即刪除 |
| 11:00～11:30 | 前往博勞座 | 導航至縣立大山停車場 |
| 11:30～12:20 | 午餐 | 大山蕎麥或山菜料理 |
| 12:30～13:10 | 大山寺 | 參拜與周邊散步 |
| 13:10～14:30 | 大神山神社奧宮 | 來回依腳程抓 60～90 分鐘 |
| 14:30～15:00 | 南光河原／參道休息 | 視體力與天候 |
| 15:15～15:45 | 開始下山 | 不拖到山區天黑 |
| 16:15～17:30 | 皆生日歸溫泉 | 時間不足時可直接刪除 |
| 17:45～18:15 | 米子還車 | 先加滿油、預留驗車時間 |
| 18:30 後 | 米子晚餐 | 選站前店家，避免再長距離移動 |

## 導航順序

1. 鍵掛峠展望台
2. 桝水高原
3. 博勞座／縣立大山停車場
4. 皆生溫泉日歸設施
5. 租車店附近加油站
6. 米子站前租車店

## 天候決策

### 晴朗

- 鍵掛峠
- 環狀道路精華段
- 桝水高原
- 大山寺
- 大神山神社

### 小雨但能見度尚可

- 鍵掛峠短停
- 刪除桝水高原
- 保留大山寺與大神山神社

### 濃霧

- 若完全看不到大山南壁，不在鍵掛峠久等
- 直接前往大山寺區
- 可將時間轉給植田正治寫真美術館或皆生溫泉

### 中大雨或強風

- 取消鍵掛峠與環狀道路
- 改植田正治寫真美術館、足立美術館延伸、松江市區室內景點或皆生溫泉

## 午餐

- 大山寺參道選當下有座位的蕎麥店。
- 點餐：大山蕎麥、山菜蕎麥、天婦羅蕎麥。
- 不綁定單一名店，候位超過 20 分鐘就換。
- 車內準備飯糰、麵包、能量棒和飲水。

## 皆生日歸溫泉

### 第一選擇：日帰り温泉 オーシャン

- 優點：營業時間長，適合行程時間不固定的自駕日
- 成人現行一般價格約 1,480 日圓
- 適合想完整泡湯、設施較充足者

### 第二選擇：おーゆ・ランド

- 優點：價格較低、效率高、停車方便
- 成人現行價格約 550 日圓
- 適合只想快速泡湯恢復體力

## 晚餐

- 若前兩天未吃鳥取和牛，可預約燒肉一八。
- 若走路疲累，直接吃米子站前牛骨拉麵。
- 若臨時改住皆生，直接吃旅館會席，不返回米子吃第二頓。

## 住宿

- 米子站前

| 時間 | 行程 | 注意事項 |

| 07:30～08:17 | 米子 → 境港 | JR 境線 |

較晚班次雖可能讓你完整逛到 10:40 或吃早午餐，但抵達航廈後距起飛只剩約 70 分鐘。若有託運行李、列車誤點或機場排隊，安全餘裕不足。

## 水木茂紀念館

- 開館：09:30
- 閉館：17:00
- 最終入館：16:30
- 全年無休
- 成人原價：1,000 日圓
- 這天不使用 1 Day Pass，直接購票即可

## D4 美食策略

由於回程航班較早：

1. 在米子飯店吃完整早餐。
2. 境港只吃小吃或買外帶。
3. 不安排需要排隊的正式海鮮餐廳。
4. 到機場後再補輕食。

若航班日後調整至較晚時間，才考慮：

- 境港地魚食堂 魚倉
- お食事処 海心
- 海陽亭 境港店

## 不加入項目

- 米子城跡
- 美保關
- 正式海鮮午餐
- 第二個博物館
