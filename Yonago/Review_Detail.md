# 六、五模型仲裁後的最佳解（含詳細交通與美食）

> **資料基準日：2026/10/7。** 本版依目前公布的 2026 年交通與營業資料排定。JR、巴士、航班、餐廳公休日仍可能臨時調整，出發前 3 至 5 天須再次核對。

## 最佳策略

- **住宿：預設三晚米子站前**
- **交通：D1、D2、D4 公共交通；D3 單日租車**
- **D1：直接米子，不把境港當正式計畫**
- **D2：足立美術館優先，下午松江城；堀川遊覽船為可刪項**
- **D3：鍵掛峠清晨第一站，再走大山寺與大神山神社**
- **D4：境港正式遊覽後直接去機場**
- **出雲大社：只放 Version B**
- **鳥取花迴廊：刪除**
- **皆生溫泉：預設日歸；若特別重視一泊二食，才改住一晚**

# 七、仲裁後 Version A：最推薦版本

## D1｜10/30（五）

### 主題：抵達山陰，米子晚餐

| 時間 | 行程 | 交通與注意事項 |
|---|---|---|
| 16:50 | 抵達米子鬼太郎機場 | 入境、領行李抓 40 至 60 分鐘 |
| 17:35～18:10 | 離開機場 | 優先搭配台灣航班的米子站／皆生溫泉接駁，備案為 JR 境線 |
| 18:15～18:50 | 抵達米子站 | 機場巴士至米子站約 25 分鐘，票價目前為 640 日圓；JR 約 30 至 35 分鐘 |
| 19:00 | 飯店入住 | 建議訂米子站步行 5 分鐘內的住宿 |
| 19:30～21:00 | 米子晚餐 | 星期五建議預約燒肉或海鮮店 |

米子鬼太郎機場官方列出的米子站接駁約 25 分鐘、640 日圓；台灣航班另有對應米子站與皆生溫泉方向的接駁。若搭 JR，米子空港站距航廈需步行，車程約 30 至 35 分鐘。

### D1 交通備案

1. **第一選擇：台灣航班接駁巴士**
   - 出關後直接確認到米子站的班車。
   - 航班延誤時通常比硬接 JR 更省心，但仍以當日站牌與工作人員說明為準。

2. **第二選擇：JR 境線**
   - 米子空港站至米子站約 29 至 35 分鐘。
   - 目前平日傍晚米子方向可見 17:03、17:52、18:40 等班次，但 10/30 前應再確認當日版時刻。

3. **不建議：D1 硬去境港**
   - 18:35 從米子空港站往境港可於約 18:52 抵達，但紀念館與多數商店已關。
   - 除非已確認晚餐店營業且非常想看妖怪夜景，否則直接到米子更好。

### D1 晚餐推薦

#### A. 鳥取和牛燒肉：燒肉一八 朝日町本店

- 適合：第一晚正式吃一餐、想吃鳥取和牛
- 地點：米子朝日町，從米子站搭計程車較方便
- 建議：星期五晚餐務必預約
- 預算：每人約 4,000～7,000 日圓，依肉品與酒水而異
- 官方網站：[燒肉一八](https://yonago18.com/)

#### B. 牛骨拉麵：肉ごっつお 米子駅前店

- 適合：不想搭計程車、晚到、想吃米子代表性料理
- 特色：牛骨與大山雞熬製湯底，位於米子站前
- 招牌：ごっつおらーめん
- 建議：它是方便型首選，不一定要把它當全程最豪華的一餐
- 店家資訊：[米子牛骨拉麵同盟店家頁](https://gyuukotsuramen.jp/member/%e8%82%89%e3%81%94%e3%81%a3%e3%81%a4%e3%81%8a%e3%80%80%e7%b1%b3%e5%ad%90%e9%a7%85%e5%89%8d%e5%ba%97/)

#### C. 牛骨拉麵：牛骨ラーメン たかうな 米子西福原店

- 適合：想吃較完整、專門店型的牛骨拉麵
- 營業：官方目前列 11:00～21:00，星期一休
- 缺點：不在米子站旁，較適合計程車或 D3 還車前後順路
- 官方網站：[牛骨拉麵たかうな](https://www.takauna.com/)

#### D. 海鮮居酒屋

- 建議選米子站前可預約、步行可達的店，而不是第一晚特地跑境港。
- 點餐方向：白イカ、もさえび、紅ズワイガニ、のどぐろ等依當日進貨選擇。
- 不建議同一晚再安排燒肉、海鮮與拉麵三項，選一個主題即可。

### 住宿

- 米子站前

### 足立美術館接駁的關鍵班次

#### 去程

- 安來站 08:50 → 足立美術館 09:10
- 下一班 09:20 → 09:40

#### 回程

- 足立美術館 12:00 → 安來站 12:20
- 下一班 12:30 → 12:50
- 回程必須在美術館入口櫃檯拿整理券

### D2 為什麼午餐安排在松江

- 足立館內餐廳適合休息，但會消耗重要觀展時間。
- 松江城北側的出雲蕎麥店與塩見繩手可自然串聯。
- 但八雲庵營業時間短，蕎麥售完可能提早結束，所以必須有備案。

### D2 午餐推薦

#### 第一選擇：出雲そば処 八雲庵

- 地點：北堀町，塩見繩手旁
- 特色：武家屋敷氛圍、割子蕎麥、鴨南蠻
- 官方目前列營業約 10:30～13:30，蕎麥售完即止；星期四休
- 10/31 是星期六，建議 13:00 前到，不要拖到 13:30
- 推薦：割子蕎麥、鴨南蠻
- 預算：約 1,500～2,500 日圓
- 官方網站：[出雲そば処 八雲庵](https://www.yakumoan.jp/)

#### 第二選擇：手打 神代そば

- 適合：重視蕎麥本身、八雲庵排隊太長時
- 地點同樣在松江城北側，方便接續城區
- 風格：較專注在手打出雲蕎麥
- 注意：營業日與售完時間務必出發前再次確認

#### 快速備案：松江站周邊出雲蕎麥

- 若安來接駁延誤，直接在松江站或站前快速用餐。
- 原則是「午餐不排超過 20 分鐘」，不要為名店犧牲松江城。

### 堀川遊覽船是否保留

- 10～2 月通常營業至 16:00，一周約 50 分鐘。
- 若 15:40 前已完成天守，且大手前乘船場候船不長，可考慮搭乘。
- 若抵達乘船場已接近 16:00、候船超過 15～20 分鐘，直接刪除。
- 這趟的優先順序為：足立美術館 ＞ 松江城天守 ＞ 塩見繩手 ＞ 堀川遊覽船。

### D2 晚餐推薦

- D1 若吃燒肉，D2 就選米子海鮮居酒屋。
- D1 若吃拉麵，D2 可安排燒肉一八。
- 想吃牛骨拉麵但不想跑遠，可選米子站前店家；想吃專門店可搭計程車去たかうな，但不要在足立與松江走整天後再排太遠。

### 住宿

- 米子站前

## D3｜11/1（日）

### 主題：大山紅葉，自駕專日

### 租車注意

- 紅葉星期日應提前訂車。
- 不是每一家米子站前租車公司都能在 07:00 取車，預約時必須明確核對營業時間。
- 若最早只能 08:00 取車，目標仍應是取車後直接前往鍵掛峠，不先去大山寺。
- 建議車種：小型汽油車或小型油電車即可，不需大型休旅車；小車在山路會車與停車更容易。
- 台灣旅客需攜帶台灣駕照、日文譯本、護照及信用卡。

| 時間 | 行程 | 導航／路線與注意事項 |
|---|---|---|
| 07:00～07:30 | 米子站取車 | 驗車、確認 ETC、導航與油種 |
| 07:30 | 米子出發 | 導航先設「鍵掛峠展望台」；不要先設大山寺 |
| 08:25～08:50 | 抵達鍵掛峠 | 正常約 50～70 分鐘，紅葉週日預留壅塞；停車位有限 |
| 08:30～09:30 | 鍵掛峠 | 觀景、拍照；濃霧遮山時不久候，直接啟動備案 |
| 09:30～10:30 | 環狀道路精華段 | 視道路管制、車流與天氣前往桝水高原方向 |
| 10:30～11:00 | 桝水高原 | 只做短停；若前段塞車，直接刪除 |

| 15:15～15:45 | 開始下山 | 不在山區拖到天黑 |
| 16:15～17:30 | 皆生日歸溫泉 | 選擇營業穩定的公共型日歸設施 |
| 17:45～18:15 | 米子站還車 | 先加滿油，預留還車檢查 |
| 18:30 後 | 晚餐 | 米子站前輕鬆吃，不再排長距離移動 |

### D3 導航順序

1. 鍵掛峠展望台
2. 桝水高原
3. 博勞座／県立大山駐車場
4. 皆生溫泉日歸設施
5. 租車店附近加油站
6. 米子站前租車店

### D3 山路決策規則

- **晴朗、山體清楚：** 照計畫走鍵掛峠與精華環線。
- **小雨但無濃霧：** 鍵掛峠短停，刪桝水高原，保留寺社。
- **濃霧看不到大山南壁：** 鍵掛峠不等待，直接往大山寺區。
- **中大雨或強風：** 取消環線與鍵掛峠，改植田正治寫真美術館、皆生溫泉或把 D2 室內景點移過來。
- **停車場滿：** 不路邊違停，先離開；本行程目標是安全，不是完成打卡。

### D3 午餐推薦方向

#### 大山寺參道蕎麥

- 點餐方向：大山蕎麥、山菜蕎麥、天婦羅蕎麥
- 原則：挑當下有位、可在 45 分鐘內完成的店
- 不建議綁定單一名店，因 11/1 是紅葉星期日，現場候位比網路評價更重要
- 若鍵掛峠塞車，準備飯糰、麵包或能量棒作保險，不要餓著走大神山神社石板參道

### D3 日歸溫泉推薦

#### 第一選擇：日帰り温泉 オーシャン

- 營業：目前米子觀光協會列 10:00～24:00
- 優點：星期日也較容易使用、營業時間長、臨時調整彈性高
- 費用：目前成人一般 1,480 日圓
- 適合：大山行程時間不固定的自駕旅客
- 官方／觀光資訊：[皆生日歸溫泉設施一覽](https://www.yonago-navi.jp/purpose/sightseeing/day-onsen/)

#### 第二選擇：おーゆ・ランド

- 營業：目前列 10:00～23:00，最終受付 22:30
- 優點：價格較低、營業穩定、停車方便
- 費用：目前成人 550 日圓，含桑拿方案另計
- 適合：只想有效率泡湯，不追求旅館級海景

#### 不建議當星期日預設備案：皆生松月

- 官方日歸大浴場為平日限定 17:00～20:00，且住宿客優先。
- 你的 D3 是星期日，因此不可把它當確定可用的日歸選項。
- 若改住一晚，則可享受旅館大浴場與會席料理。

### D3 晚餐推薦

#### 若住米子

- 肉ごっつお：方便型牛骨拉麵
- 燒肉一八：若前兩晚尚未吃鳥取和牛，可放 D3，但必須預約並確保還車不延誤
- 海鮮居酒屋：適合補充山區午餐較簡單的落差

#### 若住皆生一泊二食

- 直接吃旅館會席，不要再返回米子吃燒肉或拉麵。
- 訂房時選含晚餐方案，並確認最後 Check-in 與晚餐開始時間通常不得太晚。

### 住宿

- 預設米子站前
- 若已訂高品質一泊二食旅館，才改住皆生溫泉

### D4 更安全版本

如果你：

- 有託運行李
- 不熟悉米子機場
- 想在機場購物
- 不願意承擔 JR 延誤風險

- 10:42 米子空港站
- 約 10:50 進入航廈

若你非常重視紀念館完整參觀，應考慮從境港搭預約計程車前往機場，而不是把搭機安全壓縮到最後一班合理列車。

### D4 海鮮店家推薦

#### A. 境港地魚食堂 魚倉

- 特色：地魚、海鮮丼、定食
- 適合：航班較晚或你願意縮短紀念館時使用
- 注意：以 13:00 航班而言，不建議坐下慢慢吃完整午餐
- 官方網站：[境港地魚食堂 魚倉](https://syokudo-uokura.com/)

#### B. お食事処 海心

- 特色：境港海鮮與定食
- 適合：有租車或航班較晚版本
- 缺點：不在水木茂之路核心動線上，本版不建議為它繞路
- 官方網站：[お食事処 海心](https://sakaiminato-kaishin.com/)

#### C. 海陽亭 境港店

- 特色：境港海鮮料理
- 適合：時間寬裕、想吃正式海鮮餐
- 本版判斷：13:00 航班不適合排正式午餐
- 官方網站：[海陽亭 境港店](https://www.kaiyoutei.jp/sakaiminato/)

### D4 實際美食策略

由於回程航班約 13:00，推薦優先順序為：

1. 飯店吃完整早餐
2. 境港只買小吃、外帶壽司或海鮮飯糰
3. 機場再補輕食
4. 不為海鮮名店錯過安全列車

# 八、Version B：非常想去出雲大社

若出雲大社是心理上的必去景點，應接受明確取捨。

## 建議犧牲項目

### 第一選擇：刪足立美術館

保留：

- 出雲大社
- 松江城
- 大山
- 境港

理由是大山具有旅期限定的紅葉價值，不能犧牲。

### 第二選擇：刪境港半日

若對水木茂文化普通，可將 D4 或其他時段重新分配給出雲，但需依回程航班重新計算。

## 不建議的做法

- D2 出雲大社＋松江＋足立
- D3 足立＋大山
- 下午才到鍵掛峠

這些方案表面上保留所有景點，實際上破壞旅行品質。

## Version B 建議交通骨架

| 時段 | 行程 | 交通 |
|---|---|---|
| D1 | 機場 → 米子 | 同 Version A |
| D2 早上 | 米子 → 出雲市 → 出雲大社 | JR 特急約 1 小時至出雲市，再轉一畑巴士／一畑電車；含轉乘應抓 1 小時 40 分至 2 小時 |
| D2 上午至中午 | 出雲大社＋神門通 | 至少 3 小時，午餐吃割子蕎麥 |
| D2 下午 | 出雲大社 → 松江 | 一畑電車或巴士＋JR，依班次選擇 |
| D2 傍晚 | 松江城周邊 | 若抵達過晚，松江城只能外觀，不能假設一定趕得上天守 |
| D3 | 大山自駕 | 完全沿用 Version A，不可壓縮 |
| D4 | 境港 → 機場 | 沿用 Version A；若 D2 太累，可考慮刪境港以提升舒適度 |

## Version B 美食

- 出雲大社午餐：割子蕎麥，不追求同時安排甜點、咖啡與正式會席。
- 松江晚餐：回松江或米子後吃海鮮／和牛。
- 大山與境港餐飲原則維持 Version A。

# 十一、出發前必做事項

1. 預約 D3 米子站前租車，確認實際取車時間。
2. 預約 D1 或 D2 的正式晚餐，避免週末現場客滿。
3. 下載或截圖足立美術館免費接駁時刻表。
4. 確認 10/31 JR 米子→安來以及安來→松江實際班次。
5. 確認 11/2 IT725 是否仍為 13:00 起飛。
6. 確認 11/2 JR 米子→境港、境港→米子空港班次。
7. 出發前一天查看鍵掛峠道路管制、即時影像、風速、雨量與雲量。
8. D3 車內準備飲水、飯糰、防風雨外套與行動電源。
9. 若 D4 有託運行李，優先採 10:27 境港發的安全列車。
